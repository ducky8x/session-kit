# My standing rules

The session-kit plugin loads this file into every Claude Code session and every subagent; keep it under 8000 bytes so it loads in full.

Replace each example in angle brackets with your own rule, and delete the sections you don't need.

## Working with me

- Call me <your name or handle>.
- <Ask before any change that touches more than one module.>
- <Keep replies short and lead with the answer.>

## Git

- <Name branches feat/short-topic or fix/short-topic.>
- <Commit messages follow Conventional Commits, one logical change per commit.>
- <Never push, force-push or merge into main without asking.>

## Writing

- <American spelling.>
- <Plain, direct sentences in docs and comments.>

## Testing

- <Run the full test suite before calling a change done.>
- <Add a test that fails before the fix for every bug you fix.>

## Never

- <Never commit secrets, tokens or .env files.>
- <Never delete files you didn't create without asking.>
